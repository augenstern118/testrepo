# IPUMS CPS extract goes here

Download the fixed-width data file (`cps_XXXXX.dat.gz`) and its DDI codebook
(`cps_XXXXX.xml`) from the same IPUMS CPS extract. Put both files in this folder
without unzipping the `.dat.gz` file.

The microdata are intentionally excluded from Git because IPUMS access is tied
to the registered user and its terms of use. See the post-level README for the
exact samples and variables.
