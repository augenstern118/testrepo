# Simulated data

These files are generated by `R/01_simulate.R`, not downloaded from a survey.
`example_sample.csv` contains the original 400 simulated hourly wages; smaller
interactive samples use its first 30 or 100 observations. The population is
lognormal with arithmetic mean $30/hour and log-SD 0.35. `simulation_parameters.csv`
records the fixed seed, population parameters and repeat counts.

There are no individual identities or empirical wage observations in these files.
The post-level README documents the complete design and replication commands.
