## Data provenance and ethical collection

The snapshot is dated September 20, 2026; wages refer to May 2025 and projections
to 2025–2035. Exact URLs, original capture method, and hashes are in
`data/raw/manifest.csv`. The six BLS Summary articles were captured from public
browser pages and preserved as actual HTML fragments. rvest extracts the data
from these fragments. They are not manually reconstructed tables. Direct HTTP
acquisition was unavailable in the original authoring environment; the cached
HTML route is explicit and is what the supplied report reproduces.

No login, CAPTCHA, paywall, or access restriction was bypassed. Collection was
limited and spaced out. Reproduction uses the cached HTML, so rendering does not
request the pages again. The optional collector checks current robots rules,
uses delays, and stops on access errors. See the article for all six linked sources.

## Optional live collection

This is not necessary to reproduce the included post. From the website root:

```r
(function() {
  old <- setwd("blog/posts/post2")
  on.exit(setwd(old))
  source("R/01_scrape.R")
  refresh_sources(destination = "data/live")
  fresh <- collect_data(raw_dir = "data/live")
  print(fresh)
})()
```

A blocked live request must be stopped, not bypassed. Use a fresh destination for
each new snapshot. The article continues to use `data/raw` to reproduce the
original report. To publish new figures, deliberately change its `collect_data`
argument, review the prose, and re-render. Narrative checks stop the build if the
main rankings or shortlist change.

## Interpretation

The six careers are a selected comparison, not the entire labor market. The
$85,000 wage/10% growth/no-related-experience screen is an explicit preference
scenario; the nine-scenario sensitivity table shows alternatives. Wages are not
starting salaries, and projected annual openings are not current vacancies or
individual hiring probabilities. The blog discusses education, experience,
category definitions, geographic limitations, and individual eligibility.
