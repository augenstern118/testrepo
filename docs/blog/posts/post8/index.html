Why a 95% Wage Interval Can Miss the Truth

simulation
bootstrap
hypothesis testing
R
A simulated wage survey shows what confidence intervals promise, why some miss, and how a null test asks a different question.
Author

Junzheng Yang

Published

October 29, 2026

Imagine a city commissions a wage survey before comparing local pay with a $28-an-hour benchmark. Its report gives a mean and a “95% confidence interval.” Could a correctly calculated interval still miss the true average? Yes. The useful question is how often the procedure misses, not whether one interval comes with a guarantee.

To make that visible, I simulate a positive, right-skewed wage population with a known mean of $30/hour. These are teaching data, not observed wages or estimates for any city. The default example samples 400 independent workers. All reported numbers below use that default; the controls change the figures.

One survey, many resamples

The sample mean is $29.82. To estimate its uncertainty, I draw 4,999 samples with replacement from those same 400 wages, keeping each resample’s size at 400, and calculate each mean. Some workers appear repeatedly in a resample; others do not appear.

Figure 1. Bootstrap means from one survey. Static version.

The middle 95% of these bootstrap means gives a percentile interval of $28.75–$30.85. It includes the known $30 truth in this example. The truth is used to check the interval, never to construct it. R’s quantile documentation describes the percentile calculation.

Try 90% confidence: the boundaries move inward while the bootstrap distribution stays unchanged. Higher confidence requires a wider interval. Increasing the worker sample size addresses a different issue: more information generally makes the estimate more precise.

Start the survey over, not just the bootstrap

To check reliability, I generate 1,000 new independent surveys, constructing a separate bootstrap interval for each using 999 resamples. Merely adding more resamples to the original survey would not answer this coverage question.

Figure 2. First 60 intervals in their original order; the coverage calculation uses all selected surveys. Static version.

At 400 workers, 953 of 1,000 intervals contain $30: 95.3% coverage. The other 47 miss despite following the same rule. The 95% interpretation concerns repeated sampling, not a 95% probability assigned to a fixed parameter after observing one interval.

The result is approximate. Its Monte Carlo standard error is 0.67 percentage points; another simulation run need not produce the identical percentage. At 30 workers, measured coverage is 93.0%, illustrating that the percentile method is not guaranteed to achieve its nominal level in small samples.

The average 95% interval is $7.39 wide at 30 workers, versus $2.11 at 400. Larger surveys improve precision. Increasing the number of survey experiments instead makes our measurement of coverage less noisy; it does not add workers to any survey.

Test the benchmark using a different simulated population

Now suppose the null model has mean $28/hour, retaining the same lognormal shape. I generate 10,000 surveys under that model. The statistic is the sample mean’s distance from $28, divided by its null standard error. That error uses the null population’s known standard deviation in this teaching model.

Figure 3. Purple cutoffs define rejection; orange marks outcomes at least as extreme as observed. Static version.

The observed statistic is Z = 3.61. Only 4 null draws have an absolute statistic at least that large. The finite-simulation p-value, calculated as (extreme + 1)/(10,000 + 1), is 0.0005. At a 5% significance level, we reject this null model. The purple cutoffs, approximately ±1.96, place roughly 5% of null statistics in the rejection regions.

Change the significance level: the rejection boundaries move, but the p-value stays fixed. A p-value describes how unusual the observation is under the specified null model. It is not the probability that the null is true. This model-based test and the nonparametric bootstrap interval are distinct constructions.

The takeaway: a 95% interval describes a procedure’s approximate reliability, not certainty about one survey. Read its width alongside its confidence level, and interpret a small p-value as evidence against a specified model—not proof of an economically important effect.

Code, simulation design and replication files accompany the article. All figures and numerical statements are generated in R from a fixed, documented seed.
